RÉFÉRENCE RAPIDE

Les bases de DogeScript

Structure

doge.Start { ... }

Exécute une fois au démarrage.

doge.Run { ... }

Répète le bloc jusqu’à l’arrêt.

Console et temps

say("Bonjour")

Affiche puis passe à la ligne. sayL reste sur la même ligne.

read(age)

Lit un nombre entier saisi dans la console.

wait(1000)

Attend une seconde.

Variables et conditions

number age = 15
text nom = "Doge"
tf actif = true

Utilisez if, else, while et repeat(3).

Listes codées

textList mot = -1;2_;3

Donne « Ab c ». Le signe - donne une majuscule et _ un espace.

numberList code = mot

Traduit les lettres en nombres.

Cette version exécute le code dans le navigateur. Elle ne crée pas de fichier .exe.
